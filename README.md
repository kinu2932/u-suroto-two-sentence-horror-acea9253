A two-sentence horror story, written by a program. `main.py` (Python 3.13, standard library only) writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt`: a small brass bell tied to a sleepwalking husband's ankle rings twice from the hallway — while he lies fast asleep beside the narrator, the bell still on his ankle, silent.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
